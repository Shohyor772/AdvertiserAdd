# Blogger Marketplace

Сервис для автоматизации поиска, отбора и безопасного взаимодействия
между блогерами (YouTube, TikTok, Telegram) и рекламодателями.

## О проекте

Платформа решает три задачи:

- **Поиск** — рекламодатель находит блогеров по фильтрам (тематика, гео,
  цена, аудитория).
- **Безопасная сделка** — деньги замораживаются на счёте сервиса до
  выхода интеграции.
- **Доверие** — автоматическая проверка накруток, рейтинги, арбитраж.

## Стек

| Компонент | Технология |
|---|---|
| Backend | Python, Django, Django REST Framework |
| Frontend | React.js |
| База данных | PostgreSQL |
| Кеш и сессии | Redis |
| Фоновые задачи | Celery |
| Платёжный шлюз | YooKassa / Stripe |
| API соцсетей | YouTube, TikTok, Google |
| Контейнеризация | Docker, Docker Compose |
| Документация API | Swagger / drf-spectacular |

## Статус проекта

Проект находится на стадии начала разработки.

Подготовлены: техническое задание, пользовательские истории, варианты
использования, UML-диаграммы (вариантов использования, компонентов,
последовательности).

Подробнее — в [project-status.md](project-status.md).
