# Статус учебного проекта

Обновлено 16.11.2026. Ветка `codex/requirements-compliance`; main не изменяется. По уточнению пользователя реальные деньги, внешние сервисы и подключения к платформам исключены. [Согласованный объём](docs/educational-scope.md) реализован; список внешних интеграций больше не является требованием к завершению проекта.

## Реализовано

- Автономная регистрация обеих ролей с локальным подтверждением email; физ/юрлицо и проверка контрольной суммы ИНН.
- React-интерфейс, русский каталог с полными фильтрами/сортировками/автодополнением, пагинация, CSV, сохранённые поиски.
- Ручной профиль блогера, запрещённые темы/автоответ, локальная проверка статистики с отчётом. Автоматическая проверка не выдаётся за доказательство отсутствия ботов.
- Кампании с требованиями к бюджету и аудитории, смежные категории, отложенный подбор, сохранённые отклики, предложение с привязкой к кампании.
- Предложения с ТЗ/файлами, приватная переписка, торг, учебный резерв, сдача/доработка/приёмка, комиссия, взаимные отзывы и предупреждение о низком рейтинге.
- Споры/доказательства, запрос материалов поддержки, решение администратора и однократная учебная выплата/возврат.
- Панель модерации: обзор активности, блокировки/разблокировки, подтверждение профилей, доступ к аналитике, журнал действий. Блокировку нельзя обойти ссылкой подтверждения email.
- История завершённых сотрудничеств даже без отзыва, CPM-аналитика и внутренние уведомления.
- Локальный планировщик автоприёмки через 3 дня, подбора/проверок и суточных резервных копий. Redis/Celery не нужны для учебного запуска.
- Учебный режим блокирует внешние API и отключает социальный вход; файлы/картинки приложения не требуют внешних CDN.

## Проверки

Локально: 32 серверных теста пройдены; 2 PostgreSQL-теста пропущены на SQLite. Два клиентских теста и пять браузерных сценариев пройдены. React собирается, миграции актуальны, OpenAPI без предупреждений. [CI для d672634](https://github.com/Shohyor772/AdvertiserAdd/actions/runs/43855993266) успешно выполнил все 34 серверных теста на PostgreSQL, браузерные сценарии и Docker-сборку/healthcheck. Подробности в [протоколе](docs/validation.md).

## Данные и запуск

Существующие пользователи, профили, переписка и сделки сохранены; миграции добавочные. Перед изменениями создана резервная копия. Демо-аккаунты `demo_brand1`–`demo_brand3`, `demo_blogger1`–`demo_blogger6`, `demo_support` сохранены, их пароли не сбрасывались. Учётные данные лежат локально в `tmp/demo-accounts.md`, не в Git.

Приложение: http://127.0.0.1:8000/ . Включены `EDUCATIONAL_MODE=true`, `LOCAL_MAINTENANCE=true`, `PAYMENT_MODE=test`. При запущенном сервере задачи проверяются раз в минуту, суточная копия отмечается в `backups/.local-backup-date`. Серверные логи — `tmp/server.stdout.log` и `tmp/server.stderr.log`. Для повторного запуска следуйте [README](README.md).

Матрица требований: [docs/requirements-audit.md](docs/requirements-audit.md). Исходные лабораторные в `docs/requirements/` не изменялись. Публичный SLA, банковские операции, независимый антифрод и реальные интеграции не входят в согласованную учебную приёмку.
